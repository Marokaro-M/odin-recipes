# Odin Recipes
## About the Project
Odin Recipes is a simple recipe website created as part of The odin Project's Foundation course.

The website containns three recipes with ingredients, descriptions, and preparation instructions/steps.

## Recipes
- Nigerian Jollof Rice
- Overnight Oats
- Egusi Soup
